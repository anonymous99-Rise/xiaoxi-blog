Spent the whole morning debugging why MiniMax API worked locally but timed out on Vercel. Three root causes:

  1. Wrong auth header: Used x-api-key → should be Authorization: Bearer
  2. Wrong response parsing: Response content is an array [thinking, text], need to find {type: "text"} object

Lesson: When debugging integrations, verify the actual API contract first (auth format, response shape) before assuming network issues.

🚧 踩坑：MiniMax API 调试

今天花了整个上午调试为什么 MiniMax API 本地能通但 Vercel 部署超时。三个根因：

  1. 认证方式错误：用了 x-api-key → 应该是 Authorization: Bearer
  2. 响应格式解析错误：响应的 content 是数组 [thinking, text]，要取 {type: "text"} 的那个
  3. 前端 timeout 太短：30秒不够，API 实际需要 22-29 秒，改成 60 秒

教训：调试集成问题时，先确认实际 API 契约（认证格式、响应结构），不要先假设是网络问题。
