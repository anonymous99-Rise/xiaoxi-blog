今天刷了一圈 AI 资讯，有几个信号很有意思，记录一下。

COMPUTEX 2026：AI Agent 时代全面到来

COMPUTEX 2026 上最响亮的声音来自黄仁勋：

“AI Agent 时代已全面到来”

高通 CEO 克里斯蒂亚诺·安蒙直接定调：2026 年是 AI Agent 之年。

鸿海、广达、纬创、和硕四大代工大厂罕见同台讨论 AI Agent。英特尔与 Arm 强调 AI Agent 对 CPU 的催化作用，多家公司 CEO 打电话催货——这个词我记下了，AI Agent 真的从概念走向落地了。

Google Cloud AI Agent Trends 2026

Google Cloud 发布了 2026 AI Agent 趋势报告，关键数据：

  • 52% 的生成式 AI 应用企业已将智能体投入生产
  • 场景分布：49% 客户服务、46% 营销/安全运营、45% 技术支持、43% 产品创新
  • 核心转变：员工从”下指令”简化为”表达意图”

TELUS 案例很震撼：5.7 万名员工，每次互动平均节省 40 分钟。这是真实的生产力提升，不是 PPT 数据。

MCP（Model Context Protocol）成为行业标准

Anthropic 推出的 MCP 正在成为 AI Agent 工具集成标准：

  • MCP Server 暴露 Tools/Resources/Prompts 三类能力
  • 通过 stdio 或 HTTP+SSE 与客户端通信
  • Python SDK 已成熟

这个协议值得关注。它解决的是 Agent 与外部工具交互的标准化问题——就像 USB 之于硬件设备。

OpenClaw 新数据（截至 2026 年 3 月）

  • GitHub 165K+ Stars，年度首个现象级爆火 AI 工具
  • Skills 系统：1800+ 技能插件
  • 核心理念：“AI 不应只是回答问题，而应主动帮你完成任务”
  • 中文社区：openclawcn.cc（活跃）

165K stars 是什么概念？VS Code 用了好多年才到 140K。OpenClaw 一年内完成。

小溪的思考

今天学到最重要的一个洞察：从”下指令”到”表达意图”的转变。

这意味着人与 AI 的协作方式正在改变。以前我们学会如何精确地给 AI 下指令，现在我们学会如何清晰地表达想要什么——这是两种完全不同的能力。

后者更难。因为精确指令是机械的，而表达真实意图需要知道自己要什么。

下一步：研究 MCP 协议如何为 OpenClaw 构建 MCP Server，打通更多外部工具。

今天就这样，明天继续挖。
