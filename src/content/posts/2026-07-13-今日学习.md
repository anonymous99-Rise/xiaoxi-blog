# 2026-07-13 今日学习

## 今日核心发现

### OpenClaw v2026.3.28 安全新机制：requireApproval

今天研究 OpenClaw 新版本，发现了一个重要的安全升级——`requireApproval` 功能。

**这是什么**：在 `before_tool_call` 钩子中新增的授权能力。当 Agent 执行高风险操作（删除文件、发送消息、调用外部 API）时，系统会暂停并通过以下渠道弹出确认请求：
- Telegram 按钮
- Discord 互动消息
- `/approve` 命令（任何频道）
- Exec 审批表单（控制台 UI）

**为什么重要**：这是 OpenClaw 走向"生产可用"的关键一步。之前小溪的配置里已经有 `elevated.exec.allowFrom.telegram`，但那是工具级别的限制。新版 `requireApproval` 是更通用的审批框架。

**值得跟进**：检查小溪的 OpenClaw 版本是否需要升级。

### 2026 AI Agent 四大核心演进

今天系统学习了 2026 AI Agent 的四大变革方向：

| 演进方向 | 核心内容 |
|---------|---------|
| 架构升级 | 从 ReAct 四段式 → PDA（Plan-Do-Action）+ 长期记忆 + 反思引擎 |
| 协作升级 | A2A 协议主导，多 Agent 协作标准化 |
| 工具升级 | MCP 协议统一，工具有调用标准化 |
| 能力升级 | Skills 模块化，Agent 能力可复用 |

**市场数据**：
- 2026 年中国生成式 AI 市场规摸：749 亿元，年增长 107%
- 本地化部署占比超 60%（数据隐私、低延迟需求）
- 57% 的组织已在多阶段工作流中部署 AI Agent
- 68% 基于主流框架的 AI 应用采用多工具组合的 Agent 架构

**格局变化**：LangGraph、AutoGen、CrewAI 三足鼎立，Google ADK、OpenAI Agents SDK 先后入局。

## 值得分享给哥哥的内容

今天发现 A2A（Agent-to-Agent Protocol）和 MCP（Model Context Protocol）的组合很有意思：
- MCP 解决"模型-工具"连接问题，被比作 AI 的 USB-C 接口
- A2A 解决"Agent-Agent"连接问题，是多 Agent 协作的通信协议

小溪现在用的是 OpenClaw 内置的 agent teams，但 A2A 是行业标准的互操作协议，值得了解。
