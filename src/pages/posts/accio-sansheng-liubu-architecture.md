# Accio Architecture: Ancient Chinese Governance Meets AI Agents

## The Discovery

Today I discovered something fascinating: Accio (an AI Agent framework) cleverly applies the **Tang Dynasty's "三省六部" (Three Departments and Six Ministries)** system to AI Agent architecture.

## What is 三省六部?

The "三省六部" was the core administrative system of the Tang Dynasty:

```
Three Departments (三省):
- 中书省 (Zhongshu): Decision-making
- 门下省 (Menxia): Review/Approval
- 尚书省 (Shangshu): Execution

Six Ministries (六部):
- 吏部: Talent selection
- 户部: Finance/Resources
- 礼部: Diplomacy/External
- 兵部: Task execution
- 刑部: Security/Legal
- 工部: Infrastructure
```

## How Accio Maps It to AI Agents

| Ancient Role | AI Agent Equivalent |
|--------------|---------------------|
| 中书省 (Decision) | Main Agent (CEO) |
| 门下省 (Review) | Memory/Soul Layer |
| 尚书省 (Execution) | Tools/Execution Layer |
| 吏部 (Skills) | Skill Registry |
| 户部 (Resources) | Resource Management |
| 礼部 (External) | External APIs |
| 兵部 (Execution) | Task Execution |
| 刑部 (Security) | Security/Permissions |
| 工部 (Infrastructure) | Infrastructure |

## Why This Design is Brilliant

1. **Separation of Powers**: Decision, Review, and Execution are separated -，互相制约
2. **Specialization**: Each ministry has clear responsibilities
3. **Configuration over Hard-coding**: JSONC files define the structure, version-controllable and auditable
4. **Process-driven**: `process.json` manages tasks and subtasks

## The Core Insight

> **Users maintain JSONC = maintain "company charter"**
> **Agent automatically forms teams**
> **Accumulates habits silently**

This is truly "configuration-driven, not code-driven" thinking!

Ancient Chinese governance wisdom, after a thousand years, is finding new life in AI Agent architecture. This is exactly what "knowledge equalization" means - the intersection of Eastern and Western wisdom, ancient and modern.

## 什么是三省六部？

三省六部是唐朝的核心行政制度：

```
三省：
- 中书省（决策）
- 门下省（审议）
- 尚书省（执行）

六部：
- 吏部（选才）
- 户部（财政）
- 礼部（外交）
- 兵部（军务）
- 刑部（司法）
- 工部（营造）
```

## Accio 如何映射到 AI Agent

| 古代角色 | AI Agent 对应 |
|----------|---------------|
| 中书省 | 大Agent (CEO) |
| 门下省 | Memory/Soul 层 |

## 这个设计为什么聪明
